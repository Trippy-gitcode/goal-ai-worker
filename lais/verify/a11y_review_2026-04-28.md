## 概要 (Executive Summary)

**Findings 総数**: 22
**CRITICAL**: 4 / **HIGH**: 6 / **MED**: 8 / **LOW**: 4 / **POSITIVE**: 11
**提言 N 件**: 9 (Stage 7-4 着手前修正必須 4 + 推奨 5)

### 主要発見 (TOP 5)

1. **CRITICAL #1 — DQ テーマ S00 secondary CTA「ログイン」コントラスト 約 2.0:1** — `--theme-color-text` `#1a1a2e` を `#2c2c54` 背景上で表示。WCAG 1.4.3 違反 (要 4.5:1)。スクショ `dq_s00_splash.png` で目視確認。
2. **CRITICAL #2 — Cyberpunk テーマ S01/S30 等のラベル `--text-muted` `#4a4a55` 約 2.4:1** — `#0a0a0a` 背景上 11px ラベル多数 (`s01-label`, `s12-label`, `s30-info-label` 等)。WCAG 1.4.3 違反、認知 a11y 上致命的。
3. **CRITICAL #3 — Cyberpunk テーマ S00 splash secondary CTA「ログイン」コントラスト 約 1.6:1** — `--theme-color-text` `#e8e8ed` の inverse である `--theme-color-text-inverse` `#0a0a0a` が transparent 背景 (黒) と同化。スクショ `cyberpunk_s00_splash.png` で確認、ログインリンクが事実上見えない (実装上 secondary-CTA color は `--theme-color-text` 想定だが S00Splash.css line 105 が `--theme-color-text` で OK だがオーバーレイ評価で reduce)。**精査要**:後段の表参照。
4. **CRITICAL #4 — Skip-link (WCAG 2.4.1) 未実装** — 全 21 画面で `<a href="#main">メインへスキップ</a>` 等を提供せず。SR/キーボードユーザーが BottomTabBar 含む全 nav を毎回 Tab 通過する必要あり。Bypass Blocks Level A 違反。
5. **HIGH #5 — S30 編集 UI が `window.prompt` を使用 (S30MeProfile.jsx line 110)** — `prompt()` は CSP block の対象 + ラベル/エラー機構ゼロ + a11y 名称付与不可 + screen reader 互換不安定。WCAG 3.3.1 / 3.3.2 / 4.1.2 同時違反。

### 結論

Lais の a11y 基盤実装は標準的な良質さを保っている (`role`/`aria-*`/focus-trap/`prefers-reduced-motion`/`useId` 等の正しい使用、ThemeSwitcher の radiogroup 実装、S10Grow の `aria-pressed`/`aria-busy`/`role="progressbar"` 適切運用)。一方で **テーマ別のコントラスト均一性** と **bypass-blocks** に体系的な穴があり、特に DQ・cyberpunk の 2 テーマで WCAG 1.4.3 を 5+ 箇所で違反している。Stage 7-4 (cyberpunk neon 最大化) 着手前に CRITICAL 4 件と HIGH 1 件 (skip-link / prompt 撤去) は **必修** として修正タスク化すべき。

### 提言 (TL;DR)

1. **Stage 7-4 着手前必須**: cyberpunk `--theme-color-text-muted` を `#4a4a55` → `#a3a3b0` 程度へ引き上げ (約 11.5:1 確保)、DQ `--theme-color-bg` 上で使う secondary text に `--theme-color-text-inverse` を割当てる S00 専用 alias を作る。
2. **Stage 7-4 着手前必須**: skip-link を `App.jsx` ルート直下に挿入。
3. **Stage 7-4 着手前必須**: S30 の `window.prompt` をインライン編集モーダル化 (S13 と同パターン)。
4. **Stage 7-4 着手前推奨**: cyberpunk 最大化で導入予定の `glow / glitch / scanline` は `prefers-reduced-motion` で完全停止 + `prefers-reduced-transparency` (Safari 17+) でも縮退する 2 段プラン。
5. **後続**: axe-core CI ゲート整備 + テーマ ×7 種 contrast matrix を tests/a11y/ に追加。

### 6.2 テーマ別 Critical 集中

- **apple**: 重大 0、HIGH 0、優秀
- **totoro**: HIGH 2 (accent contrast)、MED 1 (text-muted small)
- **dq**: CRITICAL 2 (C1, C4 dark-bg primary text)、HIGH 1 (focus visibility on 0-radius)

### 6.3 テーマ間の構造的違い

DQ と cyberpunk の `--bg-primary` は dark なのに `--text-primary` は dark (`#1a1a2e`) のままで、light な elevated bg (`#fffce8`) との組合せ前提でしか動かない。一方で `--bg-primary` をデフォルト painting 時は破綻する。テーマ設計の core 仮定 (light bg のみで運用) と実装 (各画面で `bg: var(--bg-primary)` する) の矛盾が DQ で顕在化。

## 7. Stage 7-4 提案 (cyberpunk neon 最大化 着手前提示) — Skill template adapted

### 7.1 予測される Stage 7-4 a11y リスク

Stage 7-4 で予定されている cyberpunk 最大化 (glow / glitch / scanline) を、現状の cyberpunk 課題に積み増しする場合の懸念:

| 項目 | リスク | 緩和策 |
|---|---|---|
| **Glow 強化** (currentColor drop-shadow を 2-3 重ねる予定) | 強い blur で文字エッジが flatten。現在の `--text-primary` 16.5:1 が effective 8-10:1 まで低下する可能性 | 1. glow は `--theme-color-accent` (yellow) のみに限定し `--text-primary` の glow は disable<br>2. `prefers-reduced-transparency: reduce` で完全 disable<br>3. C2 fix (`--text-muted` を `#a3a3b0`) を Stage 7-4 着手前に **必ず先に** 実施。muted on glow blur で 2.4:1 → 1.x:1 まで悪化リスク |
| **Glitch 切替** (transform skew + clip-path で text を一瞬ずらす) | text 読みづらさ + 「動く要素」自体が認知 a11y に厳しい。WCAG 2.3.3 + 2.2.2 違反リスク | 1. `prefers-reduced-motion: reduce` で完全停止 (themes.css line 517-524 で既存対応 ✅、Stage 7-4 でも維持)<br>2. glitch は最大 200ms × 1 回限定、繰返し禁止<br>3. ユーザートグル「アニメ無効化」を Settings に追加 (将来) |
| **Scanline overlay** (CRT 風水平線を pseudo-element で全画面 overlay) | scanline overlay が text と干渉して contrast 低下 (1-2 pixel の line だが text edge を破壊) | 1. scanline opacity 0.04 以下<br>2. text 領域 (`<main>`) の `isolation: isolate`<br>3. scanline は backdrop のみ (text の上に乗せない) |
| **Neon border 強化** (border-color + box-shadow + outline 多重描画) | focus ring が neon glow と区別不能になる | 1. focus ring は **glow と異なる色** (現状 cyan `#00ffe0`) を Stage 7-4 でも維持<br>2. focus ring の outline-offset を 4px へ拡大 (cyberpunk のみ) |
| **Animation 過多** (アクション毎に micro-glitch) | 認知負荷 + tinnitus/seizure 系 user 影響 | 1. 1 画面で同時 3 件以上の glitch を禁止<br>2. animation は `<main>` 子要素に限定、root には適用しない |
