# GOAL AI — E2Eフルフローテスト仕様書
> 作成: 2026-04-03 / 更新: 2026-04-06（B3-B6対応: 3ステップ入力/タイムライン/ルーティン/ゲーミフィケーション/プラン別テスト）
> 目的: ユーザーが実際にやる全操作を、本番APIに対して、最初から最後まで自動テスト
> 環境: FRONTEND_BASE=https://goal-ai-frontend.pages.dev（本番URL）
> 原則: 1つのテスト = ユーザーの1つの操作フローを完遂。途中でスキップしない

---

## テスト環境

- URL: https://goal-ai-frontend.pages.dev（本番）
- 認証: auto-register（初回アクセスで自動登録）
- AI API: 本番Worker（https://goal-ai-worker.goalai-futoshi.workers.dev）
- タイムアウト: AI応答待ち最大90秒
- **モック禁止。データ注入禁止。全て実際のUI操作で行う。**
- **デフォルトテストユーザー = Maxプラン。** beforeAllでSupabase直接更新（`plan='max'`）。レート制限回避+全モデル最上位で基本フロー検証
- プラン別テスト（E2E-19）のみ、テスト内でプランを切替

## E2E-01: アプリ起動→初回認証

## E2E-02: タスク追加フロー（B3: 3ステップ入力UX）

- [ ] TODAY画面で+ボタンをタップ → タスク追加UIが表示される
- [ ] Step1: タスク名「役所に行く」を入力
- [ ] Step1: 期日プリセット（今日/明日/今週/来週/日付/なし）が表示される
- [ ] Step1: 「明日」をタップ → Step2に進む
- [ ] Step2: ローカル推論で「場所: 外出先」「時間制約: 営業時間内」がデフォルト選択されている
- [ ] Step2: 所要時間・集中力の選択カードが表示される
- [ ] Step2: 「これでOK」をタップ → タスクが作成される
- [ ] タスクがTODAYに表示される（タイトル+期日+メタデータ）
- [ ] ページリロード → タスクが消えていない
- [ ] 2件目: 「確定申告の書類を調べる」を追加 → ローカル推論で「場所: 自宅」「集中力: high」がデフォルト
- [ ] Step2で「もう少し詳しく」をタップ → Step3対話が開始される
- [ ] Step3: AIが質問（context/risk収集）→ 回答 → タスクにcontext保存
- [ ] [TASK_UPDATE]タグがユーザーに見えない

## テスト実行ルール

1. **本番URL必須。** localhost禁止。FRONTEND_BASE=https://goal-ai-frontend.pages.dev
2. **モック禁止。データ注入禁止。** 全て実際のUI操作で行う
3. **AI応答は最大90秒待つ。** タイムアウトしたらFAIL（skipにしない）
4. **各テストでスクリーンショットを撮る。** 操作前/操作後/結果の3枚
5. **フォアグラウンド実行のみ。スイートごとに分割実行**
6. **1テスト = 1ユーザーフロー完遂。** 途中で止めてPASSにしない
7. **FAILした場合: テストではなく実装を修正する**（テスト修正でPASSにしない）
8. **デフォルトテストユーザー = Max。** E2E-19のみプラン切替を行う
