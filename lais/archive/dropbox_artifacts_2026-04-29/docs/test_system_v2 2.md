## 0. 全機能・全画面の存在理由の定義

### TODAY画面
| 機能 | 存在理由 | 成功基準 |
|---|---|---|
| 挨拶（おはよう/こんにちは/おつかれさま） | ユーザーに温かみを感じさせ、時間帯の意識を促す | 時間帯に応じた正しい挨拶が表示される |
| タスクリスト | 今日やるべきことを一覧化し、完了管理する | タスクが表示され、チェック/並べ替え/削除ができる |
| +ボタン（タスク追加） | AIとの対話でタスクを構造化して追加する | ボタン→モーダル→入力→AI応答→タスク作成→リスト反映 |
| コメント欄「状況を伝える」 | 自由テキストでAIに状況を伝え、タスク調整を促す | 入力→AI応答→タスク変更が反映される |
| 日記（TODAY'S NOTE） | その日の振り返りを記録し、AIの理解を深める | 入力→自動保存→リロード後残存→タイトル自動生成 |
| カレンダーFAB | 過去の日記を閲覧する | タップ→カレンダー→日付選択→日記表示 |
| 秘書メモ | AIが生成した注意点や提案を表示する | 折りたたみ可。警告/提案の区別がある |

### TALK画面
| 機能 | 存在理由 | 成功基準 |
|---|---|---|
| チャット入力＋送信 | ユーザーがAIに相談・質問する | テキスト入力→送信→AI応答がストリーミング表示 |
| ルーティング | 質問の種類に応じて最適なAIが自動選択される | 検索系→Gemini、感情系→Claude、創造系→GPT、短文→GPT-simple |
| 賢者アイコン | どのAIが回答したか直感的にわかる | GPT=クリスタル、Claude=羽ペン、Gemini=望遠鏡のSVG |
| 新規チャット | 新しい話題を始める | ボタンタップ→空のチャット画面 |
| チャット履歴 | 過去の会話を振り返る | 左スワイプ/履歴ボタン→過去チャット一覧→タップで表示 |
| TALK→TODAY連携 | 会話中にタスク操作を行う | 「タスク追加して」→AIがタスク作成→TODAYに反映 |

### GOALS画面
| 機能 | 存在理由 | 成功基準 |
|---|---|---|
| ゴール一覧 | 中長期目標を俯瞰する | ゴール名＋進捗%＋バーが表示される |
| ゴール作成 | 新しい目標を設定する | GOALS画面内で完結。名前入力→作成→リスト反映 |
| ゴール削除 | 不要な目標を整理する | 削除→リストから消える→リロード後も消えたまま |
| ゴールハブ（5タブ） | 1つのゴールを多角的に管理する | タップ→5タブ遷移（概要/タスク/分析/設定/連携） |
| やりたいこと→ゴール昇格 | 漠然とした希望を具体的なゴールに変換する | やりたいこと入力→ゴール昇格→ゴールリストに追加 |
| ディープ分析 | AIがゴールの達成度を深く分析する | 分析タブから起動→AI分析結果表示 |

### ME画面
| 機能 | 存在理由 | 成功基準 |
|---|---|---|
| ビジョン表示 | 人生の方向性を常に意識する | ビジョンテキストが大きく表示される |
| 強み/課題 | 自己理解を視覚化する | 2カラムで強み・課題がタグ表示 |
| プロフィール編集 | AIに自分を理解してもらう情報を更新する | 編集→保存→リロード後反映→AI応答に反映 |
| AI理解メモ | AIが理解した自分像を確認・修正する | メモ表示＋「これは違う」ボタン機能 |
| 自分を知るセッション | AIとの対話で自己理解を深める | セッション開始→対話→結果がプロフィールに反映 |

### サイドバー
| 機能 | 存在理由 | 成功基準 |
|---|---|---|
| コーチングモード | AIの応答トーンを好みに合わせる | モード切替→確認→AI応答トーン変化→リロード保持 |
| チャット履歴 | 過去の会話に素早くアクセスする | 一覧表示→タップ→TALK表示 |
| 設定（テーマ/文字サイズ） | UIを自分好みにカスタマイズする | 変更→全画面即時反映→リロード保持 |
| プラン選択 | 利用プランを確認・変更する | 5プラン表示→現在プランハイライト→アップグレード導線 |

### 共通
| 機能 | 存在理由 | 成功基準 |
|---|---|---|
| ボトムタブ4つ | 主要画面間をワンタップで遷移する | 全タブからどのタブにも1タップで遷移。アクティブ状態表示 |
| auto-register認証 | 初回訪問で即座に使い始められる | アクセス→自動登録→全機能利用可能 |
| データ永続化 | 操作結果がリロード後も消えない | タスク/ゴール/日記/設定がリロード後に維持 |
| エラーハンドリング | エラー時にアプリが壊れない | エラートースト表示＋操作再開可能 |

## 2. ユーザーシナリオテスト — 50パターン（初回）→ 修正後25パターン追加

### 実行ルール
1. 50シナリオを全て実行。1つでもFAILなら実装を修正
2. 修正後、FAIL分を再テスト → 全PASSになったら追加25シナリオを実行
3. 追加25シナリオも全PASSでこのテスト完了

### シナリオ定義（1シナリオ = 1人の1日の使い方）

#### 朝の利用パターン（S01-S10）
- [ ] S01: 起床→TODAY確認→タスク3件追加→完了順に並べ替え→「いってきます」チャット
- [ ] S02: 起床→日記「今日の目標：プレゼン成功」→タスク「プレゼン資料作成」追加→GOALS確認
- [ ] S03: 起床→「今日の天気」チャット→Gemini応答→「傘いる？」追問→タスク「傘を持っていく」追加
- [ ] S04: 起床→秘書メモ確認→提案されたタスクを承認→コメント欄「午前は在宅」
- [ ] S05: 起床→プロフィール更新（使える時間:午前のみ）→タスク追加→ゴール進捗確認
- [ ] S06: 起床→コーチングモード「スパルタ」に変更→タスク確認→「気合い入れて」チャット
- [ ] S07: 起床→前日の日記を読み返す（カレンダー）→今日の日記を書き始める
- [ ] S08: 起床→ゴール「ダイエット」の進捗確認→タスク「ジム行く」追加→完了チェック
