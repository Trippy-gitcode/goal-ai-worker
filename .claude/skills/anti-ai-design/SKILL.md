GOAL AIのUI実装・mockup作成時に適用するデザイン原則。既存のデザイントークン（style.css :root）とdesign_spec_v3.mdが上流。このスキルはそれらと矛盾しない範囲で「質感」を補完する。

## AIスロップ禁止リスト

以下は「AIが生成しました」と一目でわかるデザインパターン。GOAL AIでは使用禁止:

- 紫グラデーション on 白背景（Anthropicっぽい）
- Inter / Roboto / system-ui のみの無個性タイポグラフィ
- 均等配分カラーパレット（全色同じ面積）
- 丸角カード量産レイアウト（Pinterest型グリッド）
- 中央揃え一本道の縦スクロール
- 意味のないグラデーション背景
- 過剰なドロップシャドウの重ね掛け
- ストックフォト風のイラスト・アイコン
- 「Welcome!」「Get Started」等の英語UIテンプレ

## GOAL AIのデザイントーン: 黒板 + 金箔

- **ベース:** ダークトーン（#0c0e14）— 黒板のような落ち着き
- **アクセント:** アンバーゴールド（#e4b86a）— 金箔の温かみ。控えめに使う
- **テキスト:** クリーム（#ede8dc）— 柔らかく読みやすい
- **フォント:** -apple-system + ヒラギノ。日本語ネイティブの可読性最優先
- **余白:** 狭すぎず広すぎず。情報密度は高めだが窮屈にしない
- **ボーダー:** 極細（0.5px）+ 低透明度。存在は感じるが主張しない

## 手触り感の原則

1. **重みを感じるタップ:** ボタンは押し込み感（transform:scale(0.96)）、離した時の戻り
2. **滑らかな遷移:** ページ切替は0.25s ease。急すぎず遅すぎず
3. **控えめなフィードバック:** トーストは控えめに出て静かに消える。派手なアニメは避ける
4. **呼吸するUI:** アイドル状態のパルスアニメは1.5s以上の周期。速いパルスは避ける
5. **テキストの階層:** primary/secondary/tertiaryの3段階を明確に。中間のグレーゾーンを作らない

## 実装時の判断基準

- 「これ、AIが作ったっぽい？」→ やり直し
- 「人間のデザイナーがFigmaで丁寧に作った感じ？」→ OK
- 迷ったら design_spec_v3.md のCSS値を優先
- 新しいCSS値を追加する場合は :root のトークンとして定義

## 禁止事項

- design_spec_v3.md / mockup HTML の既存CSS値を上書きしない
- 新しいフォントの追加（パフォーマンス影響）
- 外部CDNからのアセット読み込み
- CSSフレームワーク（Tailwind等）の導入
