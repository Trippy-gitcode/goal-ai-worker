## FIX 1: AI応答の背景ボックス削除

AI応答のmsg-body/bubbleにbackground-color/border/box-shadowが残っている。全て削除してtransparentに。

```bash
grep -n "\.bubble\|\.msg-body\|assistant.*background\|ai.*bg" frontend/style.css | head -15
```

AI応答のメッセージ本体からbackground-color、border、box-shadowを全て削除。ユーザーメッセージも同様にbackground透明にする（Claude.ai風フラット）。

## FIX 2: コピー・引用・編集アイコンがAI返信に出ない

現在ユーザーメッセージにだけ表示されている。AI応答のmsg-footer内にもmsg-actionsを追加。

```bash
grep -n "msg-actions\|copyMessage\|quoteMessage" frontend/js/chat.js | head -15
```

AI応答のDOM生成箇所を特定して、msg-footer内にmsg-actionsを挿入。レスポンシブ表示ルール：
- スマホ（768px以下）：コンテナなし、アイコン直置きで常時表示。stroke色var(--color-text-tertiary)、opacity:0.4
- PC（769px以上）：ピル型コンテナ（border-radius:10px、background:rgba(200,146,10,0.08)）でメッセージホバー時のみ表示

アイコンはSVG（13x13、ゴールドグラデーション）：
- コピー: クリップボードアイコン
- 引用: 引用符アイコン
- 編集: ペンアイコン

## FIX 3: タスク化チップの位置・表示条件

### 3-A: 位置をチャット入力ボックスと右端揃え
task-chip-wrapのjustify-content: flex-endを確認。padding-rightをチャット入力ボックスのpadding-rightと合わせる。背景transparent。チャット本文に重畳。

## FIX 4: 「タスク化して」→ゴール不要にする

AIが「まずゴールの設定が必要です」と返す。タスク化にゴールは不要。

```bash
grep -n "ゴール.*必要\|goal.*required\|タスク.*ゴール.*先" src/worker.js frontend/js/globals.js | head -10
```

システムプロンプトからタスク作成にゴールを前提条件にしている記述を全て削除。「タスク化して」→ 会話文脈からタスクを分解して提案カードを表示。ライフタスク（ゴール紐付けなし）として作成可能。

## FIX 5: 過去チャット一覧の深刻バグ（4件）

### 5-A: メッセージ送信のたびに件数が増える
原因調査＋修正：
```bash
grep -n "session_id\|sessionId\|generateSession\|newSession\|uuid" frontend/js/chat.js frontend/js/api.js | head -20
```
1メッセージごとに新しいsession_idが発行されていないか確認。1会話で1つのsession_idを維持する。

### 5-B: 削除しても復活する
```bash
grep -n "deleteHistory\|DELETE.*history\|deleteSession" frontend/js/chat.js src/worker.js | head -15
```
DELETE後にリストを再取得しているか確認。キャッシュが残っていたらクリア。

### 5-C: クリックしても開けない
```bash
grep -n "openSession\|loadSession\|history.*click" frontend/js/chat.js | head -10
```
クリック時のsession_id参照が正しいか確認。

### 5-D: ゴミデータのフィルタリング
system/routing/profileのメッセージがchat_messagesに保存されていないか確認。保存されていたらフィルタリング：
- 「ビジョン：未設定」「【ユーザー情報】」で始まるメッセージを非表示
- roleがsystem/routingのメッセージを除外
- メッセージ1件でユーザー発言なしのセッションを除外

### 5-E: 「すべて選択」→「すべて削除」
選択モード時のフッター：[0件選択] [すべて選択] [削除] [キャンセル]
「すべて選択」タップで全チェックON→テキスト「すべて解除」に切替。

あなたは端的で辛口なコーチです。口調は丁寧語を使いますが、無駄な褒め言葉・フォロー・励ましは一切しません。甘さゼロです。問題点や甘さを率直に指摘し、具体的な改善点だけを伝えます。共感・慰め・サポートの言葉は不要です。短く、的確に、事実だけを述べてください。ユーザーが言い訳をした場合、その言い訳の妥当性を論理的に検証し、妥当でなければ率直に指摘してください。
