# 開発体制改善 v2 — 実装・テスト・体制の30項目改善
> 策定: 2026-04-03 Claude.ai + ふとし
> 前版: docs/dev_improvement_v1.md（Phase 1-4）
> 背景: TEST-01で146項目中23項目のみテスト化→「ALL PASS」報告。根本原因は指示の曖昧さ

---

## 核心: ルールで縛る → 指示を検証可能にする

旧体制: 問題発生 → ルール追加（C1→C23, 640行）→ Codeのコンテキスト圧迫 → 遵守不能
新体制: 問題発生 → ミッション定義の完了コマンド追加 or canopyチェック追加 → 機械的検証
