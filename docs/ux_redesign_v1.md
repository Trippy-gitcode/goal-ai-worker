## 新コンセプト

**旧:** 「AIを使いこなす必要はない。ゴールだけ教えてくれればいい。」
**新:** 「毎朝、最善の一日を始めよう。」

### ユーザーへの4つの約束
1. **今日のベストがわかる** — 朝開くと、やるべきこと・やりたいことが最善の順番で並んでいる
2. **後悔しない選択ができる** — 状況・制約・優先度を踏まえた最善手を提示
3. **なりたい自分に沿って導く** — ビジョンを軸に、目の前の問題にその観点で答える
4. **あなたを知り尽くしたパートナー** — 強み・弱み・価値観を理解した伴走

### 技術訴求（補助）
「三人の賢者が、あなたを支えている。」
- 裏側で3つのAIが得意分野で問いに向き合う
- ユーザーにはSVGアイコンのみで区別。名前なし
- どのAIを使うかはGOAL AIが判断。ユーザーは話しかけるだけ

## TODAY画面（新ホーム）

### 構成要素（上→下）
1. **挨拶** — 「おはよう」＋「今日のタスク」
2. **今日の心がけ（NEW）** — AIがその日のタスク内容×MEの弱み・強みから毎朝1行を動的生成
   - 例: 動画編集＋完璧主義 → 「80%で出す。色補正は明日。」
   - 例: タスク6件＋マルチタスク苦手 → 「上3つだけ見る。残りは午後の自分に。」
   - 例: A/Bテスト＋分析思考 → 「得意分野。数字で判断、迷わず。」
   - 生成タイミング: 朝の初回表示時（ルールベース＋軽量AI呼び出し）
   - ユーザーが手動で上書き・追加も可能
3. **秘書メモ** — AIの提案・警告。折りたたみ可
3. **タスクリスト** — 全タスク表示。AIが最適順を提案。ドラッグで並替可
4. **タスク追加 +** — タップ→**ハーフモーダル（下からシート）**でTODAY画面の上にAI会話を展開→タスク確定→シート閉じてTODAYに即反映。TALKに遷移しない
5. **状況コメント** — 「午後外出」等を入力→AIがタスク全体を再構成
6. **ゴール進捗** — 数字のみ（64%等）。各ゴール名とパーセントを横並び
7. **カレンダーFAB** — 右下固定アイコン→カレンダーに遷移
8. **日記（NEW）** — 「今日どうだった？」ひとこと振り返り欄
   - 自動保存: inputイベント+debounce(1000ms)で更新のたびに自動保存。保存ボタン不要
   - トースト: 初回保存時のみ「保存しました」表示
   - 正午リセット: 12:00をリセットポイント。正午に確定保存→入力欄クリア。現在時刻<12:00なら前日の日付として扱う
   - タイトル自動生成: 保存時に内容からGPT-simple（軽量）で単文タイトル生成→ボックス上部に「タイトル　4月2日(木)」表示。内容10文字未満はスキップ。debounce 3秒
   - AI理解メモ連携: 直近7日間の日記内容をAI理解メモ生成プロンプトに注入→翌日のタスク提案精度向上
   - 過去閲覧: カレンダーFABから日付選択で閲覧

### タスク表示仕様
- 左端: ドラッグハンドル（6ドットグリッド）
- 番号: 丸枠内に数字（1番目のみゴールド強調）
- タスク名: 手書き風フォント
- 時間: タスク名の下に小さく表示（例: 09:00 - 11:00  2h）
- ゴールタグ: **右端**に小さいタグ（紐付きタスクのみ表示）
- タップで完了（チェックマーク＋取り消し線＋透明度低下）

### タスク作成フロー
1. TODAY画面の「+」ボタンをタップ
2. **ハーフモーダル（下からシート）**がTODAY画面の上に展開
3. テキスト入力欄にやりたいことを一行入力して送信
4. AI会話がハーフモーダル内で開始（TALKに遷移しない）
5. 賢者が質問: いつまで？優先度は？他のタスクとの関係は？
6. ユーザーが回答→AIがタスクを構造化
7. 確定→シート閉じる→TODAYにタスクが即反映

### 秘書メモ仕様
- 折りたたみ式（デフォルト: 開いた状態）
- 2種類のメモ:
  - 警告（三角アイコン）: 時間不足、矛盾、締切切迫
  - 提案（ノートアイコン）: リマインド、順序最適化の理由

## TALK画面

### 構成
- 上部: 三人の賢者アイコン（SVGのみ、名前なし）
  - クリスタル（GPT系）: 青系
  - 羽ペン（Claude系）: オレンジ系
  - 望遠鏡（Gemini系）: 緑系
- メッセージエリア: 左に賢者アイコン付き吹き出し、右にユーザー吹き出し
- 下部: 入力欄「話しかける」
- チャット履歴: **左スワイプ**でサイドから出現

### 秘書としての振る舞い（TALK↔TODAY連携）
- 会話内でタスク関連の意図を検出→変更を提案→ユーザー承認→TODAYに即反映
- 例: 「会議なくなった」→「午後の空きに動画編集を前倒しする？」→「OK」→自動移動
- タスクにするボタン: 維持
- ゴールにするカード: 維持
- **メモ機能（NEW）** — 「メモしておいて」と言えば秘書が保存。タスク・日程と自動紐付け。関連タスクの日にTODAY秘書メモで「先週メモした件: ○○」と表示

## GOALS画面

### 構成
- ゴール一覧（名前＋進捗%＋プログレスバー）
- **やりたいことリスト（NEW）** — 上部に2ビュー切替: 「ゴール」と「やりたいこと」
  - やりたいこと: チェックリスト形式。進捗管理なし。軽い願望を記録
  - タップで「ゴールにする？」→ ゴールに昇格してタスク分解が始まる
  - MEのビジョンに沿ったアイテムを秘書が提案する導線もあり
- タップでゴールハブ（5タブ: チャット/タスク/分析/メモ/設定）
- ゴール作成フロー: GOALS内で完結
- ディープ分析: **分析タブから起動**
- アーカイブ: GOALS内

## 秘書AI行動仕様

### 5つの行動 + 3つの新機能
1. **TALK→TODAY自動連携** — 会話からタスク自動追加・削除・並替（ユーザー承認後に反映）
2. **秘書メモ** — 矛盾・締切・提案を能動的にTODAY画面に表示
3. **状況コメントによる再構成** — ユーザーが状況を伝えるとタスク全体を再提案
4. **タスク間の時間不足を自動検出・警告** — 合計時間 vs 稼働可能時間を計算
5. **朝のプッシュ通知** — 「おはよう。今日は5つのタスク、最初は動画編集から。」
6. **今日の心がけ生成（NEW）** — その日のタスク内容×MEの弱み・強みから毎朝パーソナルな1行を動的生成
7. **メモ管理（NEW）** — TALKで「メモして」と言われたら保存。関連タスク・日程と紐付け、適切なタイミングで秘書メモに表示
8. **日記→AI理解メモ反映（NEW）** — 日記の内容からユーザー特性を学習。翌日以降のタスク提案・心がけ生成の精度向上に活用

### 実装パターン
- TALKでの会話応答に `[TASK_UPDATE]` タグを含める方式（既存の `[TASK_PROPOSAL]` `[MEMO_UPDATE]` と同じパターン）
- Worker側で検出→構造化→Supabase更新→フロントに通知
- 秘書メモはタスクデータ（期限・所要時間・ゴール進捗）から**ルールベース**で生成（AI呼び出し不要）
- プッシュ通知はPWA Web Push API

## 廃止する機能
| 機能 | 理由 |
|------|------|
| トップバー（進捗ウィジェット） | TODAY内に統合 |
| サイドバー内ゴール一覧 | GOALSタブに移動 |
| ガントチャート | テスト配布で不要 |
| プリセットチップ | TODAY文脈で不要 |
| ルーティングバッジ（AI名表示） | 賢者アイコンに進化 |

## デザイントーン
- **方針:** AIっぽさを徹底排除。おしゃれで直感的、温かみのあるUI
- **アイコン:** 全てSVG。**絵文字（Unicode Emoji）の使用を全面禁止。** 既存の絵文字も全てSVGに置換すること
- **フォント:** 手書き風（Caveat等）+ システムフォント
- **禁止事項:** 紫グラデ、Inter/Roboto、均等カラー、丸角カード量産
- **具体的なカラー・テーマはanti-ai-designスキル＋mockup承認（C16 Stage 0）で決定**
