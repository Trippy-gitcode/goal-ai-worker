## #2: ストリーミング中の送信→停止ボタン

**対象画面:** 全チャット画面の入力欄

**挙動:**
1. ユーザーがメッセージ送信
2. 送信ボタン（↑矢印）→ 停止ボタン（●丸枠+■四角）に即時切替
3. ストリーミング中にタップすると:
   - AbortControllerでストリーミングを中断
   - AIバブル内のテキストを**削除**
   - 「中断しました」テキストを薄いグレーで表示
   - ターンは消費する（APIは呼ばれている）
4. 停止ボタン → 送信ボタンに戻る

**デザイン:**
- 形状: Claude式（●丸枠 + ■四角）
- サイズ: 送信ボタンと同じ（26×26px丸）
- 枠線: 0.5px solid var(--border-tertiary)
- ■四角: 8×8px、var(--text-secondary)、角丸1px
- アニメーション: 送信→停止への切替はフェード（150ms）

**「中断しました」表示:**
- font-size: 12px
- color: var(--text-tertiary)
- 中央揃え（AIバブル内）
- タイムスタンプは表示する

## #3: ゴール検出トーストアニメーション

**対象画面:** ホームチャット

**表示条件:** AIがゴール候補を検出した時（task_potentialフラグ）

**デザイン:**
- 位置: 画面上部（ステータスバー直下、safe-area-inset-top配慮）
- 背景: var(--bg-secondary) + 0.5px border var(--gold-primary)
- 角丸: 12px
- 左にゴールド王冠アイコン（16×16px）
- テキスト: 「ゴールが見つかりました！」+ ゴール名1行
- 右にタップ→ゴール設定導線ボタン、×閉じるボタン

**アニメーション:**
- 登場: バウンス（上から落下 → 跳ね返り）
  - translateY(-100%) → translateY(0) + scale(1.02) → scale(1.0)
  - duration: 400ms、ease-out
- 退場: 上にスライドアウト（200ms）

**消滅:**
- 自動消滅なし
- ユーザーがタップ（ゴール設定画面へ遷移）or ×ボタンで閉じる
- 別のトーストが来ても押し出さない（ゴール検出トーストは最優先で上に残る）

## #4: AI理解メモ閲覧UI（#05d）

**対象画面:** ゴールハブ → メモタブ

**レイアウト:**
- 上部: 更新日時（「最終更新: 3/20 14:30」、font-size: 11px、var(--text-tertiary)）
- 本体: アコーディオン形式
  - 各項目: タイトル（太字） + 展開矢印（▶/▼）
  - 展開時: テキスト表示（font-size: 14px、line-height: 1.6）
  - デフォルト: 最初の2項目を展開、残りは閉じた状態
- 編集: 完全readonly（編集ボタン・テキスト選択のみ不可にはしない、コピーは可能）
- 手動再生成: ボタンなし（5ターンごと自動更新のみ）

**アコーディオンの項目分割:**
AIメモの箇条書き（10〜15項目）を以下のカテゴリに自動分類:
1. 性格・コミュニケーション
2. 行動パターン
3. モチベーション
4. 弱点・課題

※ 分類はフロントエンドで正規表現マッチ or AIメモ生成時にJSON構造化（後者推奨だが実装コスト高）。
MVP段階では箇条書きをそのまま1つのアコーディオンで全表示でもOK。

**空状態（メモ未生成）:**
- 中央にイラスト（吹き出し+虫眼鏡）
- テキスト: 「AIがあなたを理解中です。5回ほど会話すると、ここにAIの理解メモが表示されます。」
- font-size: 13px、var(--text-secondary)
