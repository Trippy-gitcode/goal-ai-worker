## 共通仕様

### カラーシステム
- **ブランドゴールド**: #c8920a → #f5d380 (グラデーション)
- **AIモデル名カラー**:
  - Claude: #e8913a (オレンジ)
  - ChatGPT: #5b8def (ブルー)
  - Gemini: #e07070 (優しい赤)
  - テーマごとに視認性調整（ダーク/ライト/ハラジュク各定義）
- **モードチップカラー**:
  - 通常: #c8920a (金)
  - メンケア: #28b464 (緑)
  - ソクラテス: #8b5cf6 (紫)
  - スパルタ: #dc3232 (赤)
- **フッターモデル名**: text-tertiaryグレーに統一。AI「名前」ヘッダー部分のみカラー維持 [CRN-02]
- **セパレータ**: 時刻とモデル名の間は「·」ではなくスペース。例: `11:14  Claude Sonnet` [CRN-02]
- 全UIコンポーネントはCSS変数のみ参照。ハードコード色禁止。

### 王冠アイコン（全画面統一）[CRN-01]
- **SVG**: `<path d="M5 24l4-11 3 5L16 6l4 12 3-5 4 11H5z" fill="url(#crown)"/>`
- **グラデーション**: `#c8920a` → `#f5d380`（linearGradient x1=6 y1=6 x2=26 y2=24）
- **丸背景なし**: 王冠単体表示。ベタ塗り円で囲まない
- **適用箇所**: サイドバーロゴ、ホームヒーロー48px、チャットAIアバター18px、オンボーディング

### 統一チャット入力欄（全画面共通）[CRN-03]
- border-radius: 14px（スマホ）/ 12px（PC・埋込）
- border: 0.5px solid rgba(200,146,10,0.3)
- 内部: `[プレースホルダーテキスト] [画像ボタン] [音声ボタン] [送信ボタン]`
- 画像・音声ボタン: 丸枠+SVGアイコン、border-tertiaryスタイル
- 送信ボタン: 28px円（スマホ）/ 22px円（PC埋込）、ゴールドグラデーション
- プレースホルダー: 会話前「質問、相談、なんでも...」/ 会話中「返信する」/ タスク「このタスクについて質問...」
- **ホーム・タスクチャット・ゴールハブチャット・フィードバック全て同一コンポーネント**

### フォント・間隔
- メッセージ文字サイズ16px以上、入力欄16px以上（iOS zoom防止）
- line-height: 1.5、br余白4px、p余白12px

- **コンテンツブロック**: 合計35px上にシフト（ヒーローのmargin-bottom:35px）[H02-02]

- **ゴールド区切りライン**（P-28）+ 11px gap [H02-03]
- **タスクボックス**: 208px高、ボックス内スクロール（今日→明日→以降）[H02-04]
  - 残りn/m件表示、「タスク画面→」リンク

- **ツールバー**: ☰ 🔍 🕐 モードチップ（色付き）G T ＋（グレーアウト）
  - **使用量バッジなし** [H02-01]
  - ＋は会話前グレーアウト、会話中ゴールド

## #03 ホーム全機能（会話中詳細）

### メッセージアクション
- **AIメッセージ**: コピー📋 + 引用💬 — **ホバー/ロングプレス時のみ表示** [H03-02]
- **ユーザーメッセージ**: 編集✏️（ホバー表示）
  - 再編集→再送信、前回AI応答は取り消し線で残す（P-30）

### ゴール検出カード
- トースト風スライドイン → 3秒後にタスクチップ横バッジに縮小（P-29）
- **王冠アイコンなし** — テキスト「ゴールにしますか？」のみ [H03-01]

### タスク化チップ
- 入力欄上・右揃えにフローティング
- 3状態: 非表示 / 通常 / AI判定でゴールドパルス
- 2往復目から表示 + AI判定(task_potential)で強調
- **ストリーミング中は非活性**: opacity:0.3 + pointer-events:none [H03-03]
- タスク種類: ライフタスク / ゴールタスク、重み: 🔴重要/🟡普通/🟢軽い

### ストリーミング表示
- 3ドットアニメ + 「{モデル名}が回答中...」
- **ルーティングバッジ**: SVGアイコンのみ（絵文字なし）[H03-05]
  - Gemini: 虫眼鏡SVG +「リサーチ中...」
  - GPT: 電球SVG +「アイデアを生成中...」（※電球SVG要作成）
  - Claude: バッジなし

## #04 タスク画面

### レイアウト
- PC: 2カラム（左40%:右60%）（P-35）
- スマホ: 1カラム

### 5ビュー
ゴール別 / 今日 / 3日間 / 今週 / ガント

### フィルターチップ
- すべて / ライフ / ゴール / 進行中 / 完了
- **「完了を表示」トグルは廃止** [T04A-04]
  - 「すべて」= 未完了+完了（完了は各カテゴリ内下部に自動ソート）← デフォルト
  - 「進行中」= 未完了のみ（旧トグルOFF相当）
  - 「完了」= 完了済みのみ
- **ソート「重み順」にアクティブ色（ゴールド #c8920a）** [T04A-05]

### タスクカード
- **カテゴリ名**: 11px/font-weight:600（タスク名9pxと明確に区別）[T04A-01]
- タグ順: ✨ → 重要度 → 🔁 → 期日(右寄せ固定)
- **期日なし**: 「—」表示 [T04A-02]
- **完了タスク**: 各カテゴリ内の下部に自動移動（ページ下部セクションではない）[T04A-03]
  - 完了チェックボックス: グレー背景+白チェックマーク
- 完了チェックアニメ: C案（縮小→Y軸フリップ→展開→カラフル紙吹雪5粒）（P-33）
- ヒント「タップで詳細 · 長押しで並べ替え」初回のみ（P-32）
- backスワイプ: iOS左端→右で一覧に戻る（P-34）
- **FAB重なり防止**: tlistにpadding-bottom:52px [T04A-06]

### タスク詳細（スマホ #04b）
- **タスクチャット**: アバター+名前ヘッダー形式（ホームチャットと同じ構造）[T04B-01]
  - AIアバター: 王冠+名前カラー、ユーザーアバター: 頭文字+名前
- **配置順**: メタ情報 → タスクチャット → クイックアクション → 入力ボックス [T04B-02]
  - 「クイックアクション」タイトルは不要
- **「完了報告」ボタン**: 押下時にC案アニメーション発火 [T04A-07]
- 入力ボックス: CRN-03共通コンポーネント [T04B-03]

### PC 2カラム (#04c)
- **タイトル行**: 「タスク名」+「ステータス ▾」+「重要度」を1行に [T04C-01]
- **左カラム選択枠**: 0.4αに強調 [T04C-02]
- **チャット領域拡大**: min-height:120px、flex:1 [T04C-03]
- **FAB削除** → ヘッダーに「＋ タスク追加」テキストボタン [T04C-04]
- クイックアクション: チャットと入力ボックスの間、タイトル不要 [T04C-05]
- フィルターチップで完了管理（トグル行不要）[T04C-06]
- 入力ボックス: CRN-03共通コンポーネント [T04C-07]

## #05 ゴールハブ（5タブ）
> ※以下は v1 仕様。デザインレビュー未実施。次セッションでレビュー予定。

### 共通ヘッダー

### #05a チャット

### #05b タスク
- Phase別表示 + 進捗バー
- AI提案タスク、タスク追加ボタン

### #05c 分析
- **統計3カード**: タスク完了率 / 完了タスク(n/m) / アプリ使用時間
- **月別チャート**: バーにタスク達成数/合計数を表示
- **停滞ポイント**: 日付+内容+自動タグ（外部依存/体調/時間不足等）（P-39）
- **3AIディープ分析**:
  - 2パス選択: 「自分の振り返り」（進捗レポート / 課題と次のアクション）/ 「人に伝える」（企画書 / プレゼン資料）
  - モデルバッジ（Gemini/GPT/Claude）+ 残り回数表示（P-42）
  - 「ヒアリングを開始」→ AIが2〜3問で確認 → ユーザー「出力」ボタン押下まで出力しない
  - 出力中: 7フェーズプログレスバー（P-44）
  - Freeプラン限定: 15〜30秒動画広告（スキップ不可、Proアップグレード導線付き）
  - 出力形式同時選択可能（P-45）
  - ディープ分析フロー全体（P-47）

### #05d メモ
- **AIの理解メモ**（別セクション、ゴールド枠）
- **自分のメモ**: Apple Notes風日付グループUI
  - グループ: 今日 / 過去7日間 / 過去30日間
  - 角丸カード、タイトル+日付+プレビュー1行
  - FABで新規追加（右下36px円、ゴールドグラデーション）
  - メモエディタ: @でタスク検索→挿入（P-43）
  - タスクリンク可能（P-40）

### #05e 設定
- **AIロール** — メモタブから移動して集約
  - ロールカード（アイコン+名前+説明）+ 「変更する」/「AIに提案してもらう」
- ゴール情報（タイトル/期限/KPI/進捗算出）
- レビュー頻度4択（毎日/毎週/隔週/毎月）+ 次回レビュー日
- 通知（期限リマインダー/週次レビュー）
- エクスポート（Markdown / ICS）
- ゴール管理（アーカイブ/削除）
