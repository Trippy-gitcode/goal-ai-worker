# GOAL AI — ユーザー操作テスト指示書
> 作成: 2026-04-02 Claude.ai
> 目的: 全機能に対してユーザー想定操作を網羅的にテストし、不備を修正する
> ルール: 各テストを実際に実行し、結果を記録。FAILは即修正。全PASSになるまで繰り返す
> 重要: grepやコード確認だけではPASSにしない。実際にブラウザ/シミュレーターで操作すること（A7）

## 1. タスク作成フロー（最優先 — 現在バグあり）

### 1-1. TODAY「+」ボタンからのタスク作成
- [ ] +ボタンをタップ → ハーフモーダル（下からシート）が表示される（TALKに遷移しない）
- [ ] テキスト入力欄にタスク名を入力できる
- [ ] 送信後、AIが時間・優先度・関連タスクを質問する
- [ ] AIとの会話でタスクが構造化される
- [ ] 確定後、シートが閉じてTODAYにタスクが表示される
- [ ] 作成されたタスクがSupabase/localStorageに保存されている
- [ ] リロード後もタスクが残っている

### 1-2. TODAYコメント欄からのタスク作成
- [ ] 「状況を伝える」欄に「今日やること：買い物」と入力→送信
- [ ] AIがタスクとして認識→[TASK_UPDATE]が発行される
- [ ] [TASK_UPDATE]タグがユーザーに見えない（生テキスト非表示）
- [ ] タスクがTODAYリストに反映される

### 1-3. TALKチャットからのタスク作成
- [ ] TALKで「タスク作りたい」と入力→送信
- [ ] AIがタスク内容をヒアリング
- [ ] [TASK_UPDATE:add:...]が発行される
- [ ] **[TASK_UPDATE]タグがチャットに表示されない**（現在バグ: 生テキスト表示）
- [ ] タスクがTODAYリストに反映される
- [ ] TODAYタブに切り替えて確認できる

### 1-4. TALKの「タスクにする」ボタンからのタスク作成
- [ ] AIの応答後に「タスクにする」チップが表示される
- [ ] タップ→タスク作成フロー開始
- [ ] タスクが正しくTODAYに追加される

### 1-5. [TASK_UPDATE]タグのパース（最重要バグ）
- [ ] Worker側で[TASK_UPDATE]タグが検出されること
- [ ] 検出されたタグがフロントエンドに返る前にストリップされること
- [ ] タスクデータがSupabaseに保存されること
- [ ] フロントエンドにタスク追加通知が送られること
- [ ] ユーザーに[TASK_UPDATE]の生テキストが一切見えないこと

### 1-6. タスクの編集・完了・削除
- [ ] タスクをタップ→詳細が表示される
- [ ] タスクのチェック（完了）→取り消し線＋opacity低下
- [ ] 完了状態がリロード後も保持される
- [ ] タスクの削除が機能する

### 1-7. タスクの並べ替え
- [ ] ドラッグハンドル長押し→ドラッグ→順序変更
- [ ] 変更後の順序がリロード後も保持される

## 2. TALK画面

### 2-1. 基本チャット
- [ ] 入力欄にテキスト入力→送信→メッセージ送信
- [ ] AI応答がストリーミング表示される
- [ ] ユーザーメッセージ右寄せ、AI応答左寄せ
- [ ] タイムスタンプ表示

### 2-2. 賢者アイコン
- [ ] GPT→クリスタルSVG、Claude→羽ペンSVG、Gemini→望遠鏡SVG
- [ ] 旧テキストバッジ（「Claude Opus」等）非表示
- [ ] 賢者の名前なし（SVGアイコンのみ）

### 2-3. ルーティング
- [ ] 「東16のダイヤを教えて」→ Gemini（現在バグ: Claude）
- [ ] 「今日の天気は？」→ Gemini
- [ ] 「やる気が出ない」→ Claude
- [ ] 「アイデア出して」→ GPT
- [ ] 「おはよう」→ GPT-simple

### 2-4. チャット履歴
- [ ] 左スワイプ→チャット履歴パネルスライドイン
- [ ] 過去チャットタップ→切り替わる
- [ ] 新しいチャット開始できる

### 2-5. メモ機能
- [ ] 「〇〇メモしておいて」→AI「メモしました」→保存
- [ ] 関連タスクの日に秘書メモに表示される

### 2-6. TALK→TODAY連携
- [ ] 「会議キャンセル」→AIがタスク変更提案→承認→TODAY更新
- [ ] [TASK_UPDATE]タグ非表示

### 2-7. 入力ボックス
- [ ] キーボード表示/非表示でレイアウト崩れない
- [ ] 入力欄とボトムタブが重ならない（現在バグ）
- [ ] デザインが全画面統一

## 3. TODAY画面

### 3-1. 挨拶
- [ ] 〜11時:おはよう、〜17時:こんにちは、17時〜:おつかれさま
- [ ] 日付正しく表示

### 3-2. 心がけ欄
- [ ] AI生成の心がけが表示（タスク×MEの弱み強みベース）
- [ ] 同日中は同じ内容（キャッシュ）

### 3-3. 秘書メモ
- [ ] 折りたたみ可能
- [ ] 警告（三角）と提案（ノート）区別

### 3-4. タスクリスト
- [ ] 全タスク表示。番号・名前・時間・ゴールタグ
- [ ] ゴール紐付きは右端タグ、なしはタグなし
- [ ] タスクなし時:「タスクがありません」

### 3-5. 日記（TODAY'S NOTE）
- [ ] 入力→debounce 1秒で自動保存（毎回）
- [ ] 初回保存時のみトースト
- [ ] リロード後も内容保持
- [ ] 正午リセット（確定保存→クリア）
- [ ] 内容からAI単文タイトル自動生成→ボックス上部に表示
- [ ] タイトル＋日付が表示される

### 3-6. カレンダーFAB
- [ ] 右下アイコン→カレンダー遷移
- [ ] カレンダーから過去日記閲覧
