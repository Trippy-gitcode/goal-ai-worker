## パターン別分析

### パターン1: スケーリング差（mockup 340px固定 vs 実装レスポンシブ）
全画面で共通。font-size, padding, icon sizeが実装の方が20-50%大きい。
**これは意図的なUXデザイン判断の可能性が高い。** mockupは視覚参考であり、実装は可読性・操作性を優先している。

該当: #01(6件), #02a(5件), #02b(3件), #04a(3件), #05a/c(5件)

### パターン2: 構造差（タグ名・コンポーネント設計が異なる）
- サイドバーモードチップ: span→button+SVG
- ヒーローモデル名: テキスト→バッジ
- タスク行: .tc compact→.task-row rich
- GoalHubタスク: CSS class→全インラインスタイル
- 自分を知る入力欄: CRN-03統一→紫テーマ独自

### パターン3: 機能未実装
- ユーザーメッセージ編集（AN）
- ビジョン「5年後/やりたくない」セクション
- 再分析6チップUI
- SNS共有
- Connect画面オレンジ閾値
- AIメモアコーディオン
- AIロール展開UI

### パターン4: mockupのみの要素（実装不要の可能性）
- ステータスバー（OSが描画）
- ソフトウェアキーボード（OSが描画）
- タッチゾーン（別の方法で実現）
